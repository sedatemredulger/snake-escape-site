# Snake Knot — gizlilik sitesi (GitHub Pages)

Bu klasördeki üç dosya, Google Play'in zorunlu tuttuğu gizlilik politikası
sayfasını oluşturur. Barındırmak ücretsiz, alan adı gerekmez.

## Yükleme (git bilmene gerek yok)

1. GitHub'da **public** bir depo aç: `snake-escape-site`
2. Depoda **Add file → Upload files** → bu klasördeki üç dosyayı sürükle:
   `index.html`, `gizlilik.html`, `privacy.html` → **Commit changes**
3. **Settings → Pages** → Source: `Deploy from a branch`,
   Branch: `main`, klasör: `/ (root)` → **Save**
4. 1-2 dakika bekle. Adres hazır.

## Play Console'a girilecek adres

```
https://<github-kullanıcı-adın>.github.io/snake-escape-site/gizlilik.html
```

Bu adresi **App content → Privacy policy** alanına yapıştır.

| Sayfa | Adres |
|---|---|
| Giriş (iki dile de link verir) | `.../snake-escape-site/` |
| Gizlilik politikası (TR) | `.../snake-escape-site/gizlilik.html` |
| Privacy policy (EN) | `.../snake-escape-site/privacy.html` |

## Metnin kapsamı

- Tek uygulama: **Snake Knot**. Ayrı bir çocuk sürümü yok.
- Veri sorumlusu: **Düka Games** (Sedat Emre Dülger, Ankara).
- Hedef kitle 13+; Google Play Families programına dahil değil.
- Reklam (AdMob), uygulama içi satın alma ve çökme raporu beyan edilmiş durumda.
- Play Console'daki **Data safety** formunun cevapları bu metinle birebir uyumlu.
  İkisi çeliştiği anda uygulama reddediliyor — birini değiştirirsek diğerini de
  güncelleyeceğiz.
